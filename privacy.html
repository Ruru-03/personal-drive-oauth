개인용 Google Drive 연동의 목적과 데이터 접근, 보관 및 연결 해제에 관한 안내입니다.

적용일 · 2026년 10월 12일   /   운영자 · Ruru-03

1. 이용 목적과 적용 범위

Personal Drive OAuth는 운영자 본인이 Windows와 Linux에서 Google Drive를 연결하여 AI 작업 결과물을 주고받기 위한 개인용 연동입니다. 일반 이용자를 대상으로 가입이나 서비스를 제공하는 용도로 운영하지 않습니다.

이 방침은 안내 웹사이트와 Google Drive 연동에 관한 내용을 구분하여 설명합니다. 실제 인증과 파일 작업은 별도의 실행 도구에서 이루어집니다.

실제 도구의 설정 확인
사용할 프로그램, 요청 권한, 파일·토큰의 저장 위치와 보관 기간은 아직 확인되지 않았습니다. 연동을 사용하기 전에 해당 도구의 설정과 동의 화면에서 확인해야 하며, 구현이 확정되면 이 안내를 갱신합니다.

2. 안내 웹사이트의 정보 처리

홈페이지, 개인정보처리방침과 서비스 약관은 정적 안내 페이지입니다. 페이지 자체에서 Google 로그인, OAuth 인증이나 Drive 파일 전송을 수행하지 않으며, 운영자가 추가한 입력 양식, JavaScript, 방문자 분석 도구 또는 쿠키가 없습니다.

웹사이트 호스팅 제공자인 GitHub는 보안 목적으로 방문자의 IP 주소를 기록·보관합니다. 이에 관한 내용은 GitHub Pages의 데이터 수집 안내와 GitHub 개인정보처리방침에서 확인할 수 있습니다.

3. Google Drive 접근과 이용

Google 계정의 인증과 Drive 서비스 이용에 따른 정보 처리는 Google의 개인정보처리방침에 따릅니다. 연동 도구에 허용하는 권한은 Google의 동의 화면에서 확인할 수 있습니다.

연동 도구가 접근할 수 있는 파일·폴더 정보, 파일 내용 및 가능한 작업의 범위는 요청하고 승인한 권한에 따라 달라집니다. AI 작업 결과물 교환을 위해 수행하는 업로드·다운로드 등에는 해당 데이터가 실행 환경과 Google Drive 사이에서 전송됩니다.

OAuth 토큰은 실제 연동 도구가 승인된 Google Drive 작업을 수행하는 데 사용됩니다. 토큰의 구체적인 저장 위치, 보호 방식 및 보관 기간은 사용하는 도구의 구현과 설정에서 확인해야 합니다.

4. 파일 보관과 다른 서비스의 이용

Google Drive에 올린 결과물은 해당 계정의 파일로 보관되며, 내려받거나 복사한 결과물은 실제로 선택한 저장 위치에 남을 수 있습니다. 이 안내 웹사이트가 파일의 보관 기간이나 삭제 시점을 관리하지는 않습니다.

외부 AI 서비스나 다른 프로그램의 사용 여부, 해당 서비스로의 파일 전송 및 보관 방식은 실제 작업 도구와 설정에서 확인해야 합니다. 해당 서비스를 사용하는 경우 그 서비스의 개인정보처리방침도 확인해야 합니다.

5. 연결 해제와 데이터 삭제

Google 계정의 제3자 연결 관리에서 앱의 연결을 해제하여 Google 계정 접근 권한을 취소할 수 있습니다.

Google 계정에서 접근 권한을 취소하는 것만으로 이미 내려받은 파일, 복사한 결과물이나 각 도구가 보관한 토큰 사본이 모두 삭제되는 것은 아닙니다. 필요한 경우 실제 연동 도구의 인증 정보 삭제 기능을 확인하고, Google Drive 및 각 저장 위치의 파일을 별도로 정리해야 합니다.
